# Features of Heavens Above

This page describes the key features of the Heavens Above project.

## Task Management
- Create, edit, and delete tasks.
- Assign tasks to projects or team members.
- Set due dates and priorities for each task.

## Project Tracking
- Organize tasks into projects.
- Visualize project progress with charts and dashboards.
- Filter tasks by status, priority, or assignee.

## Notifications
- Receive email or in-app notifications for task updates.
- Stay informed about approaching deadlines.
- Customize notification preferences.

## Utilities
- Built-in helper functions to simplify workflow.
- Export data in multiple formats.
- Integration with external APIs for additional functionality.
